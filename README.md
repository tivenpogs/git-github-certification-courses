# Git/GitHub Certification Courses  

#Overview  
This repository documents my journey in completing the Git/GitHub Certification Courses from Simplilearn.  
It includes my learning progress, reflections, and application of Git/GitHub skills in my projects.  

#Learning Progress  
- Completed **Git Tutorial (Simplilearn)**  
- Completed **Learn Git Basics (Simplilearn)**  
- Practiced Git commands such as `clone`, `branch`, `checkout`, `merge`, and `rebase`.  
- Worked with local and remote repositories.  

#Reflections  
- I learned how powerful Git is in tracking changes and collaborating with others.  
- Branching and rebasing were challenging at first, but now I understand how to use them effectively.  
- I appreciated how GitHub can serve as a portfolio to showcase my projects.  

#Application  
- Used GitHub to manage my **Game Hub Center** project.  
- Merged branches into main to simulate real-world project collaboration.  
- Uploaded certificates as proof of completion.
